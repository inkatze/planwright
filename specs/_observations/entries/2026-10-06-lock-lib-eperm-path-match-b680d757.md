In a worktree named for worker-permission-ergonomics every stale lock is therefore never broken: test-step-record.sh (dead writer lock) and test-run-tests-pool.sh (dead ticket reclaim) fail deterministically there and pass from a path without the word (found 2026-10-06 by that spec's Task 5 gate). The same applies in production to any install or checkout path carrying the word. Matching only the text after the last "kill:" (or testing errno-specific wording such as "No such process" first) would remove the path from the decision.
