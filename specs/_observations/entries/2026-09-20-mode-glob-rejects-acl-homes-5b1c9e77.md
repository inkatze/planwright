- 2026-09-20 [planwright] The owner-only mode globs in scripts/tower-reply-hook.sh (lines 157, 204, 229) and scripts/tower-queue.sh (967, 991, 1048) absorb the macOS xattr `@` and the SELinux `.` suffix with `[@.]*` but not the POSIX ACL `+`. Reproduced: `setfacl -m u:99998:rx` on a 0700 directory makes `ls -ldn` print `drwxr-x---+`, which matches no arm of the glob, so a fleet home carrying an inherited default ACL is refused outright. Fail-closed, so nothing unsafe is accepted; the cost is that a sound home is rejected and the refusal message tells the operator to `chmod go-w`, which cannot clear a `+`. Found by the gemini panel pass on PR #477 and deliberately not fixed there: six globs across two files share the gap, so patching only the hook would recreate the very hook/queue divergence that PR exists to remove, and the misleading message is part of the fix. Wants one change across both files, message included, rather than a glob tweak.
