- 2026-11-05 [planwright] A mission-control session running on another machine is not reachable from this one: SendMessage and ListAgents only see sessions on the local host (and Remote Control sessions when that is connected), so notes between two machines' mission control sessions need a manual relay; in the reported case the operator used ssh plus a tmux paste into the other session, which stages text without submitting it. Minor; worth a supported cross-machine relay path (for example a shared inbox file both mission controls poll, or Remote Control registration for mission-control sessions) or a documented recipe.
