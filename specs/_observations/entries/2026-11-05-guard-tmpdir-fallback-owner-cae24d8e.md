- 2026-11-05 [planwright] When a worker's recorded scratch root fails the command guard's owner check, the guard drops the scratch arm but still stages its declared-step output under the inherited TMPDIR (worker-command-guard.sh, HOOK_TMP_BASE). Worker roots now live in /tmp/planwright-<uid>, a parent only the user may write, so this needs that parent itself gone (a reboot, or a temporary-file cleaner aging an idle fleet's tree) and another local user recreating the path; the guard would then write and read its staging files in that user's directory. The fallback should be mktemp under /tmp unless TMPDIR is this user's own and writable by no one else.
