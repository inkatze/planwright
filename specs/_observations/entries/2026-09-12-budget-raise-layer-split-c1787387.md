- 2026-09-12 [planwright] The instruction-budget raise mechanism splits a raise across delivery layers: the raise| rationale must live in config/instruction-budget-exemptions.txt, which ships with the core config, while the raised knob can only live in a repo-tracked overlay, because a raise measured against config/defaults.yml cannot be recorded in that file without moving the baseline. In any tree that lacks this repository overlay (an adopter install that copies config/), check-instructions reads the entry as stale and fails closed. Surfaced while landing the tower-comms closure raise; the workaround is a clause in the rationale. A durable fix belongs to instruction-headroom: either the guard scopes raise| entries to the layer that holds the knob, or the rationale file gains an overlay layer of its own.
