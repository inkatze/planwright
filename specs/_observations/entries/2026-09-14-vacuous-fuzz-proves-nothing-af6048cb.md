- 2026-09-14 [planwright] A 400-program random-token fuzz of the awk screen reported zero bypasses and was worthless: instrumenting it showed 0 of 400 programs were EXEC-capable at all (random token soup is almost never valid awk), so it only ever tested the guard against syntax errors. The same run structured as a differential fuzz - templates that are valid awk with a live command pipe, crossed with every hiding context - produced 496 EXEC-capable programs of 1152 and was real evidence. Lesson: before believing a fuzz or adversarial sweep that finds nothing, measure how many of its inputs could have failed; an all-green sweep with no dangerous inputs is the same vacuous pass as a test suite asserting nothing.
