- 2026-11-05 [planwright] fleet-dispatch-worktree.sh reconcile judges a task worktree live only by its own tmux session name or a dispatch marker younger than LIVENESS_TTL (900s). A mission-control launch (scripts/mission-control-launch.sh) placed with --task has neither after 15 minutes: no tmux session under that name on stream-json, and nothing refreshes the marker. If /orchestrate later dispatches the same unit before its first commit, the reconcile reads the worktree as a stale orphan and runs git worktree remove --force under a live session. mc-reclaim.sh likewise decides liveness from processes only and ignores launcher rows, so a reclaim between placement and session start can remove a just-placed worktree. Candidate fix: both consult the launcher registry rows (their cwd field) before any removal.
