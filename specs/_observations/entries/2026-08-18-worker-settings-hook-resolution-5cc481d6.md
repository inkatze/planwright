- 2026-08-18 [planwright] fleet dispatch: the shipped config/worker-settings.json PreToolUse hook references ${CLAUDE_PLUGIN_ROOT}/scripts/worker-command-guard.sh, but when the fragment is passed to a stream-json-persistent worker via `claude --settings <file>`, CLAUDE_PLUGIN_ROOT does not resolve and the hook silently never registers (worker events show SessionStart hooks only, no PreToolUse). Result: every Bash command outside the static allow list (even read-only ls/git status compounds) becomes a control_request, and the fleet stalls on benign permission prompts (observed 2026-08-16 tower session: tower-anchor-integrity and tower-guard-coverage each parked ~41h on their first exploratory command). Machine-local workaround in use: generate a resolved copy of the fragment with the hook command and a literal-path Bash allow rewritten to the plugin cache absolute path, and pass that via --settings. Permanent fix candidates: dispatch-time settings generation in the streamjson launcher (resolve plugin root at launch, as fleet-dispatch-env does for its pin), or shipping the fragment with a documented generation step instead of a raw ${CLAUDE_PLUGIN_ROOT} reference.
