On the operator's macOS host a process exec costs 14.7-16.7 ms from a fleet worker session against 0.7 ms on the GitHub Linux runner (a fork without exec: 0.8 ms against 0.28 ms), and each exec costs about 13-14 ms of opendirectoryd CPU, even for /usr/bin/true: opendirectoryd runs near 0.8 of a core during an exec loop against 3-7 ms/s idle. Because that daemon is one process, it serializes execs machine-wide: the parallel full run (15 jobs) took each slowest-half file 4.9-17.3x its serial time (median about 12x), and serial runs are 3-9x CI. The same launches from an attended terminal cost about 4 ms, so the amplification is tied to the session's process tree. Any shell-layer cost measured only on Linux understates the macOS cost by the serial 3-9x, and by more under parallel load.
