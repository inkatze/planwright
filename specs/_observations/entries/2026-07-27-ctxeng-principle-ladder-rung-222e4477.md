- 2026-07-27 [planwright] The instruction-headroom restoration ladder in doctrine/instruction-hygiene.md has four rungs (diet / point-of-use reclassification / budget raise / exemption) and rung 1 is bounded by "moving law verbatim in meaning", so NO rung sanctions the move the Claude-5 guidance actually recommends: converting a rigid STYLE rule into a principle the model applies with judgement (their example, "never write multi-paragraph docstrings" becoming "match the surrounding comment density"). Every planwright trim is therefore forced to be a compression, never a loosening, which caps how much headroom a diet can ever recover. Change: add a rung 0 "principle conversion" ahead of diet, admissible ONLY for authoring-style and presentation rules, with a written exclusion set that names the hard invariants (never merge, never force-push/amend/squash/rebase, never act on a non-Ready/non-Active spec, never auto-chain /orchestrate into /spec-kickoff, the freshness gate) plus everything the safety floor covers (any rule whose non-reading could let the model take a forbidden action) plus anything a script, hook, or deny-glob already enforces deterministically. Require each conversion to cite the specs/_observations fragment or incident the rule was defending against, and to fail the conversion if none exists or if the incident recurs under the looser wording. Risk: the whole value of this rung is in the exclusion set; mis-scoping one safety invariant as style reintroduces a documented failure, which is a regression and not a simplification.
