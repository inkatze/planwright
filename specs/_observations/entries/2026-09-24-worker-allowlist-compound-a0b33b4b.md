- 2026-09-24 [planwright] Stream-json workers pend on their first compound or variable-built Bash call (for example R=PWD then R/scripts/spec-validate.sh, or a fish -c wrapper): config/worker-settings.json matches only literal prefixes and the tower may never answer, so an unattended fleet stalled within seconds of launch (2026-09-24, all 3 workers). Out-of-the-box candidates: a dispatch-prompt preamble telling workers to use one plain command per call with literal absolute plugin-script paths (the plugin-script-invocation doctrine they currently ignore); a read-only allow tier (ls, cat, head, tail, wc, grep, rg, jq, find, sed -n, gh pr checks, gh pr diff, gh api); and worker-command-guard approving simple compound commands whose every segment is independently allowed. Allowing fish -c is NOT a fix: deny rules cannot see inside the shell string, so it drops the never-force-push and never-merge guards.
