- 2026-09-02 [planwright] scripts/obs-record.sh runs mktemp "$entries/.obs-record.XXXXXX" with stderr UNSUPPRESSED, unlike the neighbouring mkdir, cd and ln calls which are all 2>/dev/null precisely so a caller-supplied path never reaches the terminal. mktemp's failure message embeds the full template path, so a --obs-dir carrying escape bytes plus a pre-existing unwritable entries/ puts them on the operator's terminal, which is the one hole in the file's documented 'never echoes raw untrusted input' property.
