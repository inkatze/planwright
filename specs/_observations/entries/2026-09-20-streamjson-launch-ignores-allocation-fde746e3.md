- 2026-09-20 [planwright] fleet-streamjson.sh launch takes no model argument and sets none, so a worker runs on whatever the claude CLI defaults to. fleet-resource-select.sh select execution returns opus/high for an execution unit, and the dispatch doctrine says to resolve the tier and apply it to the launch, but nothing in the launcher enforces or even accepts that. A tower calling launch directly (as this one did for four review and fix workers) silently ran them all on claude-fable-5-1 instead of opus, exhausted that model quota, and only found out when a later launch died with error rate_limit and empty logs. The tier is advisory unless every caller threads it through by hand. Worth either giving launch a --model/--effort it forwards, or having it resolve the tier itself from the scope it is already given.
