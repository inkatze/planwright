- 2026-09-02 [planwright] The doctrine index guard (check-doctrine-index.sh) asserts only a row-to-file bijection; it never reads the "Primary citations" column. So an index row whose citation cell disagrees with its own doc's Citations line is invisible to tooling, and the convention that they mirror each other is carried only in commit messages and reviewer memory. On tower-front-door Task 1 this cost three separate review findings against ONE row: an earlier commit fixed the row's D-IDs only, a later pass found the REQ half still six short, and a third found the row's prose describing the flight boundary without "specless" - the same over-broad reading already fixed in the doc body. All three were prose-guard-shaped: a check comparing a doc's Citations line against its index row's citation cell would have caught the first two mechanically, red-then-green, and would have made them Auto-applicable rather than sign-off items. Possible follow-ups for /spec-draft to weigh: extend check-doctrine-index to diff the citation cell against the doc's Citations line, or add a sibling pin-check in the style of the Task 2 glossary and Task 12 README pins.
