- 2026-09-26 [planwright] scripts/config-get.sh resolves the core defaults from PLANWRIGHT_ROOT/CLAUDE_PLUGIN_ROOT before its own script root, so a script run from one checkout while the session plugin root points at another install reads that install's defaults: a key added on a branch (flight_pr_hosts) reads as absent (exit 3) and the other install's repo-tracked overlay can leak in. Consider preferring the calling script's own root for defaults.
