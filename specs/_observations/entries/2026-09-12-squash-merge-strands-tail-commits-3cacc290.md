- 2026-09-12 [planwright] A squash merge silently strands any commit made on the branch AFTER the squash: the PR closes at its recorded head, the branch keeps its later commits, and nothing looks at them again. Two cases found by one GC sweep on 2026-09-12. worktree-marketing held 8cd3e34, an operator-authored observation fragment from 2026-08-27 (2026-08-27-superpowers-interop-a8d7dfb2.md) that had been absent from main for sixteen days. planwright/tower-front-door/task-2 held a fragment plus tests/test-vocabulary-inversion.sh, though that branch never had a PR at all. observation-carry.sh cannot find these: it carries fragments on the CURRENT HEAD, so a fragment on a branch nobody checks out is invisible to it forever. The sweep only surfaced them because it compared each local tip against the SHA GitHub actually merged - the comparison no routine pass makes. A periodic carry that walked every local branch rather than HEAD would have caught both on the next cycle.
