- 2026-07-24 [planwright] Several tests/*.sh files run under set -eu and write negative assertions as `grep -q PATTERN && fail "..."` or `out=$(cmd) && fail "..."`. Under set -e an AND-list whose first command fails carries the whole list non-zero status, so the PASSING branch of the negative assertion aborts the file mid-run. The runner records that as a failure, so it is fail-safe rather than a silent green, but the diagnostic is a bare non-zero with no FAIL line. Known instances: tests/test-migrate-format-version.sh (placement-sections check), and the pattern recurs. tests/test-spec-parse-corpus.sh introduces refute/refute_line case-based helpers as the safe form; worth a sweep to convert the rest.
