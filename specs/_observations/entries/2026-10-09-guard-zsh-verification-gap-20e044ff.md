- 2026-10-09 [planwright] The worker and tower command guards model zsh (the Bash tool shell on macOS) as well as bash, but no test runs their fixtures under zsh: the development hosts lack it, and the macos-latest CI job, whose image ships /bin/zsh, runs only the awk-sensitive suites. So zsh-only false-allow hypotheses (cd +N dirstack, extended_glob/brace_ccl operands, read-only ZSH_* specials) are argued from documentation, never reproduced; running the guard fixtures through zsh on that job would turn them into tests.
