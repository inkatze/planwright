- 2026-11-16 [planwright] scripts/run-tests.sh now gives each test file its own process group on a host with no timeout(1) (perl setpgrp), so a stopped process a file leaves behind can no longer orphan the runner's group into a kernel SIGHUP (the macos-suite exit 129 in run 43891341884). Two openings of the same class remain: busybox's timeout makes no group, so on the Alpine leg a file still shares the runner's group (companion to obs:9e55a84a's busybox deadline gap), and reap_dispatch's cancel path SIGSTOPs the xargs dispatcher, which sits in the runner's own group. Neither has been seen to fire; grouping the busybox path through the same perl wrapper would close the first, and would change the file-only signalling tests/test-run-tests-deadline.sh allows for there.
