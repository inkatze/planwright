- 2026-10-07 [planwright] The shared command-guard tokenizer models bash, but the Bash tool runs zsh on macOS. zsh reads <-> or <1-99> as a numeric glob over digit-named files where the tokenizer sees two redirects, and inside double quotes the tokenizer drops every backslash while bash and zsh keep one before any character other than $, a backtick, a double quote, a backslash or a newline. Read-only verbs are unaffected, since extra or different operands stay reads, but any shape whose verdict rests on an operand's exact path is not: the tower guard's temp-file rm now defers on an input redirect and refuses a quoted operand as an interim fix for the backslash case (see the double-quote backslash follow-up). zsh also expands the $=X, $~X, $^X and $+X parameter forms, which the guard reads as literal text. Both guards carry the same tokenizer model in two copies, so the root fix belongs in both.
