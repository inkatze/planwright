- 2026-09-24 [planwright] converge-sync-main.sh builds its fetch command from ${GIT_SSH_COMMAND:-ssh} plus -o BatchMode=yes and exports GIT_SSH_COMMAND, which git ranks above core.sshCommand. On a host whose remote access depends on core.sshCommand (here: an on-disk key with IdentitiesOnly, because the 1Password agent is auto-locked), the convergence sync fetch therefore authenticates without that key and fails (seen 2026-09-24, guard-coverage Task 8 worker). Fix: fall back to `git config core.sshCommand` before bare ssh when GIT_SSH_COMMAND is unset, then append BatchMode as now.
