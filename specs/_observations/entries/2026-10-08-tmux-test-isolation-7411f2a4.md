- 2026-10-08 [planwright] On 2026-10-07 an uncommitted end-to-end check in tests/test-orchestrate-relay.sh killed the host's real tmux server twice (15:07 and 15:23), taking every tmux session on the machine down. Cause: the test ran inside a tmux pane, so TMUX pointed at the real server, and tmux honours TMUX over TMUX_TMPDIR; the test's supposedly isolated new-session landed in the real server and its TMUX_TMPDIR-scoped kill-server killed that server. Rule worth enforcing: any test that starts tmux must use an explicit socket (tmux -S with a private path) or run under env -u TMUX -u TMUX_PANE together with a private TMUX_TMPDIR (unsetting TMUX alone falls back to the default socket, which is the real server), never TMUX_TMPDIR alone; a lint over tests/ (and over scripts that spawn throwaway tmux servers) could enforce it. The relay-direct-messaging flight's PR carries the fix for that one test.
