- 2026-10-20 [planwright] scripts/substrate-baseline.sh --capture-wallclock reads the duration of the Run mise run check step of the ci workflow check job. Since CI split that job into lint, test shard, and aggregate check jobs, runs after the split have no such step, so a capture whose window includes them fails closed with no timed check step. The wall-clock it should read after the split is the workflow run or the slowest shard, not one step.
