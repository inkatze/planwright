- 2026-11-06 [planwright] policy-guard refuses the common idiom `cd X || exit 1; git push`: a cd ending in || is never followed, so the later push, merge or rewrite meets need_dir and is denied, though the act can only run after the cd succeeded. (`|| return` is not equivalent at top level: bash reports the error and carries on in the old directory, so only inside a function or a sourced file would it be safe.) Seen in review of the conditional-cd fix (2026-11-06); behaviour unchanged by it. Fix shape: follow a cd whose || leads to a lone exit, and nothing else in that list.
