- 2026-08-24 [planwright] check:githooks fails inside orchestrator-created worktrees. The guard compares core.hooksPath against the tracked relative value githooks, but this clone records an absolute path to the primary checkout in the shared .git/config, which every worktree inherits. The result is that mise run check can never go fully green from a task worktree, so every /execute-task run has to reason about whether its own red CI task is its fault. Either the guard should accept an absolute path resolving to a tracked githooks directory, or wire-githooks.sh should set the relative form so worktrees inherit something that resolves locally.
