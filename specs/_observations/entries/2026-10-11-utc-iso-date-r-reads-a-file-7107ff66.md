- 2026-10-11 [planwright] The utc_iso helper copied byte-identically into scripts/fleet-throttle.sh, scripts/fleet-stats.sh and scripts/quota-hold.sh tries `date -u -r <epoch>` first. On BSD that formats the epoch; on GNU date `-r` names a FILE and prints its mtime, so when the current directory holds a file named after the epoch (an all-digit name) the rendered reset or hold time is that file's mtime instead (reproduced: a file named 1800003600 touched to 2001 made a quota hold push "stated reset 2001-01-01"). Unlikely in practice but silently wrong. Fix all three copies together, keeping them identical: try `date -u -d "@$1"` first, or pick the form once by probing `date -d @0`.
