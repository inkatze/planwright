- 2026-10-05 [fleet] Workers on one host don't coordinate test or execution runs. Each starts its own suites whenever it reaches a checkpoint, so concurrent workers contend for the same CPU and per-exec user lookups and slow each other down, with no shared view of what the host is already running. Nothing schedules heavy runs across the fleet (a host semaphore, a queue, or one worker running a shared batch for several units) to use the machine well.
