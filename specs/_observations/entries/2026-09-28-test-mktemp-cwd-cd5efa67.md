- 2026-09-28 [planwright] Many tests take their scratch dir as tmp="$(cd "$(mktemp -d ...)" && pwd -P)" with an EXIT trap removing it. Under /bin/bash 3.2 (the macOS suite shell) cd "" succeeds, so a failed mktemp (full disk, unwritable TMPDIR) makes $tmp the current directory, the repo root under mise, and the trap deletes it. The two spec-location tests now check mktemp before the cd; the others still carry the one-step form.
