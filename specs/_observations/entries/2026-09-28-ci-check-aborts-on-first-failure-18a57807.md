- 2026-09-28 [planwright] CI runs the whole gate as one `mise run check` job, and mise stops every sibling task when one fails. When scan:secrets went red on an unrelated ref, the run ended after two of 230 test files, so the job showed one red check while the test suite, shell lint and the other guards never finished. A reader of the checks list sees only the first failure and cannot tell the rest passed. Running the gate with continue-on-error, or splitting the scan into its own job, would keep one red guard from hiding the others.
