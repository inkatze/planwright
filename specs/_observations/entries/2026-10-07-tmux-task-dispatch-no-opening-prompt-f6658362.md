- 2026-10-07 [planwright] On the tmux backend, fleet-dispatch-worktree.sh dispatch <spec> <id> refuses any positional launch argument (the escalation pin admits only --model, --fallback-model, --effort, --continue and --resume), so a task worker starts as a bare idle session with no /execute-task turn. The only sanctioned way to hand it the command is the buffer-paste relay, which stages the line but never submits it, so every unattended tmux task dispatch waits on an operator keystroke before any work starts. The flight arm already solves this with --brief (one fixed prompt naming a confined brief file); the task arm needs the same shape, for example a fixed prompt naming the unit and a tower-written brief file under the fleet home, so an unattended tmux fleet can start its own workers.
