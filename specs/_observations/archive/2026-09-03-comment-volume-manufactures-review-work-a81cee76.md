- 2026-09-03 [planwright] Comment prose in source is not a tidiness issue, it is a work-generating machine in an LLM review pipeline, and it is now measurable. MEASURED 2026-09-03 across scripts/*.sh: 128 files, 57,744 lines, 20,807 comment lines against 33,843 code lines (0.61 comment:code). The mass is not annotations: only 3 percent of comment lines are single-line, while 30 percent live in just 139 blocks of 25 lines or more. The largest single header block is 252 lines (fleet-liveness.sh), longer than most files entire code; fleet-presence.sh 167, fleet-usage-gate.sh 145, fleet-fence.sh 130, fleet-attention.sh 125. WHY IT COMPOUNDS: every prose claim is an untested assertion about behaviour, and the Discovery-Rigor lens set explicitly hunts doc-versus-code mismatch (Documentation, Cross-file consistency). So prose volume does not merely cost tokens once at write time, it manufactures review findings forever, and each finding costs a commit, a checklist entry, and a human sign-off decision. Evidence from the same session: the release-please workflow header stated a safety guarantee the code could not deliver (obs c2afd203); docs/fleet.md claimed the ledger shows what a worker said when the text never enters it; the tower-front-door polish pass produced 30 commits to change 42 insertions and 24 deletions of doctrine prose, a 30-commit sign-off checklist generated almost entirely by wording alignment. The pipeline spent its most expensive resource (opus review passes at roughly 20 dollars each) reconciling prose with prose. PRECEDENT FOR THE FIX: check-instructions.sh already bounds instruction-file size on the reasoning that instruction files grow monotonically and instruction-following degrades as the load grows, with per-file warn/error knobs and a config/instruction-budget-exemptions.txt escape hatch. The same guard shape applied to source comments would bound the header essays without touching the rationale that genuinely cannot be recovered from code. Note the irony that check-instructions.sh makes this argument in a 22-line prose header.
