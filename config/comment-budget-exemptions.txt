# Comment-block budget suppression list.
#
# scripts/check-comment-budget.sh reads this file as data, never evaluated;
# doctrine/comment-hygiene.md is the rule, and the guard's --help holds the
# exact entry grammar. Blank lines and lines beginning with '#' are ignored.
# One entry per path, the path repository-relative. Two forms, each requiring
# a reason:
#
#   exempt|<path>|<reason>
#       Permanent. Only for an own-surface section the disposition taxonomy
#       offers no split and no other home, or for a file where the heredoc
#       limit (a heredoc body line beginning with '#' counts as a comment
#       line) misfires. The reason says which.
#
#   pending-cleanup|<path>|Task <N>|<reason>
#       Transitional. Names the cleanup task whose family owns the file. That
#       task's PR removes the entry at the latest; an earlier PR that brings
#       the file under every threshold removes it too, and the guard's
#       cleanup warning is the signal. Under --closeout every entry of this
#       form is an error.
#
# The pending-cleanup entries below were generated, not hand-written: every
# file the error threshold caught when the guard landed, under the cleanup
# task whose path list in the prose-disposition bundle's tasks.md names it:
# Task 6 the fleet family, Task 7 its orchestration, allocation, spec and
# release families and the five single scripts it lists, Task 8 the rest.
# They are grouped by task so that each cleanup PR removes one contiguous
# group and parallel cleanup PRs do not conflict.
